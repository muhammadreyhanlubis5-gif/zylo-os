Quick Install Guide

  1. 1

    Connect your ZYLO robot (ESP32-C3) via a USB-C data cable.

  2. 2

    Use a supported browser like Google Chrome or Microsoft Edge.

  3. 3

    Click install below and select your ESP32's COM port.

Your browser does not support Web Serial. Please use Google Chrome or Microsoft Edge on a desktop PC. You must allow serial access to install the firmware.
