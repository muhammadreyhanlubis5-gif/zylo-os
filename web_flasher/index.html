Spesifikasi & Kapabilitas

👀

Ekspresi Dinamis ZYLO

Mata ZYLO dirancang agar terlihat hidup. Menggunakan sistem *state-machine* di C++, mata akan berkedip secara natural setiap beberapa detik. Ekspresinya juga bisa berubah seketika menjadi gembira, kaget, sedih, atau marah berdasarkan stimulus dari lingkungannya.

👆

Interaksi Sensor Sentuh

Terintegrasi penuh dengan sensor kapasitif (TTP223). Cukup usap bagian kepala ZYLO, dan dia akan bereaksi seketika!

🎵

Umpan Balik Audio

Menggunakan passive buzzer (PWM), ZYLO memainkan *startup jingle* saat dinyalakan dan berbagai efek suara unik untuk setiap ekspresi emosinya.

⏱️

Mode Jam (Clock)

Dapat berfungsi sebagai jam meja pintar. Layar OLED akan menampilkan waktu *real-time* sembari mata robot berpindah ke sudut layar.

⚡

Performa ESP32-C3

Diotaki mikrokontroler canggih yang mungil namun bertenaga, sanggup merender animasi OLED 128x64 dengan *frame rate* mulus.

🌐

Sistem Web Flasher Instan

Sistem OS ini dibangun 100% *cloud-ready*. Pengguna hanya membutuhkan kabel data dan browser web untuk memasang firmware ZYLO, membuang jauh kerumitan Arduino IDE. Sangat sempurna untuk distribusi massal.
